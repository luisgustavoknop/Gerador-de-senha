# Gerador-de-senha
## Funcionalidades:
- Geração instantânea de senhas;
- Escolha do número de caracteres (4 a 32);
- Inclusão de: letra maiúscula letra minúscula, símbolos e números;
- Barra indicativa da força da senha;
- Interface responsiva;
- Atualização automática da senha sempre que uma configuração é alterada.

## Responsividade:
- O projeto foi desenvolvido para funcionar em diferentes tamanho de tela, oferecendo uma boa experiência tanto em computadores, quanto em dispositivos móveis.

## Objetivo do projeto:
- Este projeto foi desenvolvido com fins educacionais para praticar conceitos de desenvolvimento front-end,incluindo:
- Eventos em JavaScript;
- Organização de código;
- Geração aleatória de caracteres;
- Responsividade com CSS.
